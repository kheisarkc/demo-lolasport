# Fondasi pengembangan

Status: kontrak setup teknis, bukan spesifikasi seluruh aplikasi.

## Acceptance criteria
- F-01: Laravel dan Next.js terpasang dengan dependency lockfiles.
- F-02: PostgreSQL lokal memiliki database pengembangan dan pengujian terpisah.
- F-03: endpoint kesehatan memeriksa koneksi database; web dapat meneruskan hasilnya.
- F-04: lint, typecheck, build, analisis PHP, dan pengujian scaffold dapat dijalankan.
- F-05: browser desktop dan mobile dapat membuka halaman awal tanpa overflow horizontal.
- F-06: konteks proposal, keputusan terbuka, workflow agent, dan instruksi menjalankan proyek tersedia.
- F-07: skill dan MCP dipasang di repo tanpa mengubah permission global atau menghubungkan produksi.

## Di luar cakupan
Implementasi fitur bisnis, keputusan komersial pengelola, UAT manusia, serta deployment.
