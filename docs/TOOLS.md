# Tool demo

Lockfile mengunci Laravel 13.37.0, Sanctum 4.3.3, Next 16.4.2, React 19.3.0, Pest 4.7.8, Larastan 3.13.0 dan Playwright Test 1.64.1. PHP proyek 8.4 dengan PostgreSQL extension; PostgreSQL 17 Docker.

Spec Kit CLI 1.2.1/runtime mandiri. Skill lokal disalin dari fondasi; lisensi dipertahankan dalam .agents. Workflow utama Spec Kit, pendukung Laravel best practices, systematic debugging, verification-before-completion, frontend design dan Playwright.

Boost application-info dan search-docs berhasil dibaca pada awal sesi melalui MCP fondasi (read-only). MCP kemudian tidak tersedia; vendor/dokumentasi Next lokal yang versinya sama dibaca langsung. Konfigurasi MCP demo disiapkan sendiri. Tidak ada klaim bahwa koneksi MCP demo atau Context7 telah diuji aktif pada sesi ini.

Hasil pemeriksaan aplikasi demo aktual ada pada specs/001-demo/verification.md. Tidak mewarisi klaim tes fondasi.
